# 任务卡（由规划者或协调者填入实际值）

- 需求ID / 本需求绝对根 / 权威TODO / 当前运行project_root：
- task / phase / owner / attempt：
- 父任务 / 子任务或聚合标记 / 原AC覆盖 / 替代派单与交接检查点（如适用）：
- REQ / AC / 业务完成条件：
- 硬依赖 / 跨需求产物、固定版本与接受证据（如有） / 验收后的接续候选：
- 实际 base commit / worktree / 分支创建责任：
- 最小阅读集 / 已接受契约版本：
- 允许修改文件 / 共享文件与资源 owner：
- 输入 / 输出 / 成功与失败恢复行为：
- 开发自测 / 独立测试场景和环境 / 所需证据：
- 弱 OCR / 具体强审查需求和门禁（无则说明）：
- ACK / 状态 / 回执路径：
- 停止或升级条件 / 授权范围：

父聚合任务只验收子产物，不重复派完整实现。接续候选只有在依赖已接受、输入齐全、无冲突且 owner 空闲时才派发。
