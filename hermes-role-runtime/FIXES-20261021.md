## 运维入口

以下 prepare **不发送消息**，只整理机械观察 outbox，不影响业务账本/租约：

```sh
python3 monitor_notifications.py prepare --outbox /absolute/monitor/outbox
```

配置为 outbox 上一级 `delivery-policy.json`，默认值及可发布模板位于 [deployment/monitor-delivery-policy.json](deployment/monitor-delivery-policy.json)。未知配置项拒绝；默认和实际覆盖值进入完整 `code_version()` 指纹和发布包。六小时仅触发展示摘要，不是事实过期或恢复证据。

精确用量复核例子：

```sh
python3 usage_audit.py --database /absolute/role-usage.db \
  --start 2026-10-20T00:00:00+08:00 --end 2026-10-21T00:00:00+08:00 \
  --time-basis started_at
```

终态通知归档由 `monitor_queue.archive_terminal(outbox, before=<截止Unix秒>, max_items=100)` 执行；建议保留七天再归档。它保留源 hash/完整回执，不归档 UNKNOWN，不移除当前滚动窗口内发送证据。scope/heartbeat 继续使用 `execution_retention.py` 的完整退出证明，不用通知过期代替进程证明。终态枚举走索引，源事实仍可查。
