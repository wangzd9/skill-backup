# 全链最终态收口确认轮

适用：多轮返修已收敛（历轮意见都声称修完）、`上次审查head..HEAD` 零增量、用户仍指令"和之前一样调用codex审查"——此时不起空 diff 轮，改审**完整链最终态**，价值 = 证明无回退 + 挖跨 commit 组合问题 + 给下游强模型复审留最终态独立记录。

## 范围与快照
- 范围 = 原始 base..HEAD（整条返修链，非上一轮增量）；`git diff --stat` + `git log` 给全量 commit 清单（交付/合入分开列）。
- 快照仍用新 worktree（前轮先 remove），命名 `codex-review-<新轮号>`。

## prompt 模板
开头定性 + 范围 + "本轮不是增量复审，而是最终态收口确认"，然后两问：

**A. 遗留复核**——逐条列出历轮所有意见 ID（如 M-1/M-2/M-3、R-01/02/03、后续评论），要求确认在最终 HEAD 上"确实全部落地且口径一致"，**特别要求查"某轮修完又被后续轮覆盖回去"**（多轮返修最易回退点：注释与代码、断言与实现、历轮修复互相冲突处）。输出 = 意见→落地/未落地 + 文件:行号 的表。

**B. 最终态新问题**——以全链视角（明确说"而非单 commit"）列编号维度：
1. 迁移/版本链最终状态（单 head、ID 宽度、全仓旧值可执行残留 grep AST）；
2. 被修机制的完整口径自洽（如：修复代码 + 注释 + 回归用例 + 断言四者一致，grep 确认无同模式残留）；
3. 测试夹具最终状态（全调用点一致性、碰撞风险）；
4. 历轮修复互相作用的**跨文件组合问题**（字面量漂移失配、mock/patch 作用域与断言机制交互、多次改动的叠加副作用）；
5. 文档/表述最终状态（全仓 grep 已纠过的错误口径有无残留——历史轮只纠了正文漏了标题/环境行/其他回执是常见情况）。

结尾固定输出格式（A 表 + B 分级发现或明确"未发现" + 总结论）。

## 裁决与收口
- A 节"未落地/口径不一致"逐条核实后按 SKILL.md 分诊处置；B 节 info 级文档残留走"当前改正文、历史加顶部纠错标注"，仓库内 docstring 回派 owner。
- **A 全落地 + B 零代码缺陷** → codex 审查链正式收口：落 `reviews/codex-<轮号>-<date>-verdict.md`，含**历轮结论表**（轮号/范围/收口时间/token/结论/处置，时间为实查值、跨天带日期），同步 TODO 主线"N 轮全部收口"，清理快照，剩余门禁转强模型/测试者。
